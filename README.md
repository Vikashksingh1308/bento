## Features

- **Keyboard Shortcuts** — 19 actions for halves, quarters, thirds, maximize, center, and display moves
- **Drag-to-Snap** — Drag a window to a screen edge or corner to snap it into position
- **Customizable** — Remap any shortcut to your preference through the Settings panel
- **Menu Bar App** — Lives in your menu bar, always accessible, never in your way
- **Multi-Monitor Support** — Move windows across displays with a single keystroke

---

## Default Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Left Half | ⌃⌥← |
| Right Half | ⌃⌥→ |
| Top Half | ⌃⌥↑ |
| Bottom Half | ⌃⌥↓ |
| Top Left | ⌃⌥U |
| Top Right | ⌃⌥I |
| Bottom Left | ⌃⌥J |
| Bottom Right | ⌃⌥K |
| Left Third | ⌃⌥D |
| Center Third | ⌃⌥F |
| Right Third | ⌃⌥G |
| Left Two Thirds | ⌃⌥E |
| Center Two Thirds | ⌃⌥R |
| Right Two Thirds | ⌃⌥T |
| Maximize | ⌃⌥↩ |
| Center | ⌃⌥C |
| Restore | ⌃⌥⌫ |
| Next Display | ⌃⌥⌘→ |
| Previous Display | ⌃⌥⌘← |

All shortcuts can be remapped in **Bento → Settings → Shortcuts**.

---

## Requirements

- macOS 12 (Monterey) or later
- Xcode

---

## Build from Source

Open `Bento.xcodeproj` in Xcode and press **⌘R** to build and run.

On first launch, grant Bento **Accessibility** permissions when prompted in System Settings → Privacy & Security → Accessibility.
